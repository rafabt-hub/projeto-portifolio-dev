# Developer Portfolio Page 👨‍💻

![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)
![Tech](https://img.shields.io/badge/tech-Vanilla%20JS-F7DF1E?logo=javascript)

A clean and responsive personal portfolio website for a developer, built with pure HTML, CSS, and JavaScript to showcase skills, experience, and projects.

## ✨ Features

-   **Interactive Tab Navigation:** A JavaScript-powered tab system to switch between different content sections (e.g., skills, experience).
-   **Structured Sections:** Clearly organized sections for "About Me," "Education," "Portfolio," and "Contact."
-   **Fully Responsive Design:** The layout adapts seamlessly to all screen sizes, from mobile to desktop.
-   **Vanilla Stack:** Built entirely with fundamental web technologies, demonstrating strong foundational skills.

## 🛠️ Tech Stack

-   **HTML5**: For the semantic structure of the page.
-   **CSS3**: For all styling and the responsive layout.
-   **JavaScript (Vanilla)**: For interactive elements like the tab navigation.

## 🚀 Getting Started

This is a front-end only project. No installation is required.

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/rafabt-hub/dev-page-project.git
    ```
2.  **Open the file:**
    Navigate to the project folder and open the `index.html` file directly in your web browser.
